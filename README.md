# 🚀 Marsh Rocket Landing Animation

A clean and minimal landing page animation where a rocket smoothly lands on Mars — built using pure HTML and CSS. No JavaScript. Just vibes and keyframes.

1. Clone the repository:

   ```bash
   git clone https://github.com/Rohit908460/Marsh-Rocket-Landing-Animation
   ```
